# Как помочь

Больше всего проекту нужны **задания**: каждое новое — польза для всех учеников сразу.

## Что можно добавить

| Что | Где | Как проверяется |
|---|---|---|
| Генератор номера ОГЭ | `app/content/oge_gen.py`: функция `gN(seed)`, регистрация в `GENERATORS` | ответ считается программой, не вписывается руками; один сид — один и тот же вариант |
| Задача по Python | `app/content/tasks.py` | эталонное решение проходит тесты, заготовка (`starter`) — нет |
| Предложение для русского | `app/content/ru.py` | разметка запятых/орфограмм разбирается, правило из `RULES` |
| Опечатка, неточность в уроке | `app/templates/guides/`, `app/content/` | — |

Правила для заданий:
- формат и сложность — как в демоверсии ФИПИ текущего года;
- без чужих торговых марок, политики, насилия;
- текст для подростка: на «ты», коротко, без сюсюканья.

## Как добавить генератор номера ОГЭ

Генератор — функция, которая по случайному генератору `r` строит один вариант:

```python
def g11(r):                                   # r — random.Random, другого источника случайности не брать
    a, b = r.randint(2, 9), r.randint(10, 99)
    return {
        "text": "Чему равно %d × %d?" % (a, b),   # условие; абзацы через пустую строку, **жирный** можно
        "answer": str(a * b),                    # ответ считает программа, руками не вписывать
        "explain": "%d × %d = %d." % (a, b, a * b),
        # по желанию: "table": [[заголовок], [строка], …], "code": "фрагмент программы",
        # "check": lambda given: ...  — если верных ответов несколько
    }
```

Регистрация: `GENERATORS = {…, 11: g11}`. Тест `test_oge_generators_are_consistent` сам проверит 200 сидов:
поля не пустые, эталон принимается, «zzz» — нет, вариант воспроизводится по сиду, ответ не утекает в браузер
и не меньше 150 разных вариантов.

## Порядок

1. Форк → ветка → изменения.
2. `python -m pytest` — все тесты зелёные. Новая функция — новый тест.
3. Pull request: что добавлено и зачем. CI прогонит тесты сам.

## Данные учеников

Всё личное в базе принадлежит ученику (`student_id`), ученику — данные только из его сессии, никогда из запроса.
Тесты изоляции (`test_students_are_isolated` и соседние) не ослаблять. Никаких внешних счётчиков, CDN и трекеров:
сайт работает только со своего сервера.
