# umedu — бесплатная подготовка к ОГЭ между занятиями

Открытая платформа для школьников 8–9 класса, их родителей и преподавателей: информатика и Python, русский язык.
Ученик занимается 10–15 минут в день в игре с рангами и сундуками, задания каждый раз новые, ответы проверяются сами.
Всё бесплатно, без рекламы, код открыт.

## Что умеет

**Ученику**
- **План на сегодня** — 3–4 коротких шага, в конце сундук.
- **Python в браузере** (Pyodide): 34 урока, задачи с автопроверкой на скрытых тестах, черепашка, песочница.
- **Тренажёр ОГЭ по информатике**: бесконечные варианты номеров 1–10 и 12 — генератор собирает задание и сам считает
  ответ; исполнитель «Робот» (№15) с проверкой на нескольких полях; пробник с таймером.
- **Русский язык**: запятые, орфограммы, грамматическая основа, диктанты; ошибки возвращаются на повторение (1–3–7–14 дней).
- **Игра**: ранги, герои, сезон с наградами, достижения — за учёбу, а не за покупки.
- **Самостоятельный темп**: урок засчитывается, когда решена большая часть его задач, следующий открывается сам.

**Родителю**
- Кабинет со входом, все дети в одном месте: прогноз балла ОГЭ по номерам, дни занятий, домашки, сертификаты.

**Преподавателю**
- Пульт «кому нужна помощь», проверка домашек, тесты и срезы, журнал, сводка недели.
- Аналитика: воронка, где ученики бросают, задачи-стопперы, слабые номера ОГЭ и правила русского.

## Как пользоваться

1. **Готовый сайт** — [umedu.ru](https://umedu.ru) (бесплатно).
2. **Свой сайт** для школы или репетитора — [docs/SELF-HOSTING.md](docs/SELF-HOSTING.md), запуск в Docker за 10 минут.
   Данные учеников остаются у вас.
3. **Помочь проекту** — новые задачи, генераторы номеров ОГЭ, правила русского, исправления: [CONTRIBUTING.md](CONTRIBUTING.md).

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
bash scripts/fetch_vendor.sh          # Pyodide, CodeMirror и шрифты — хранятся у себя, чужие CDN не нужны
python manage.py init                 # база и учётка преподавателя
CQ_DATA_DIR=./data CQ_COOKIE_SECURE=0 uvicorn app.main:app --reload
python -m pytest                      # тесты
```

Стек: FastAPI, Jinja2, SQLite, без сборки фронтенда. Карта кода:

| Где | Что |
|---|---|
| `app/main.py` | приложение, middleware, общие функции (`render`, `back`, …) |
| `app/*_web.py` | маршруты по разделам: ученик, ОГЭ, русский, портфолио, родители, преподаватель, химия |
| `app/content/` | уроки, задачи, генераторы ОГЭ (`oge_gen.py`), русский (`ru.py`) |
| `app/game.py`, `season.py` | трофеи, ранги, сезон, дропы |
| `app/theme.py` | слова и названия, зависящие от экземпляра |
| `tests/` | тесты; новая функция — новый тест |

Настройки экземпляра — переменные `CQ_*` в `.env` (см. `.env.example`).
