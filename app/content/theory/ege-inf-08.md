# Разобраться: №8. Комбинаторика

## Правило

Словом считается любая последовательность букв, не обязательно осмысленная. Здесь алфавит из 5 букв, одна из них — Л, остальные 4 — не Л.

Удобно считать по числу букв Л. Обозначим его $k$. Остальные $5 - k$ мест заполняются любой из 4 не-Л-букв, то есть дают $4^{5-k}$ вариантов для каждого удачного набора позиций. Главный вопрос — сколько способов поставить $k$ букв Л так, чтобы они не были соседними:

- $k = 0$: 1 способ, слов $4^5$;
- $k = 1$: 5 позиций, слов $5 \cdot 4^4$;
- $k = 2$: из $\binom{5}{2} = 10$ пар позиций 4 пары соседние (1–2, 2–3, 3–4, 4–5), остаётся 6 способов, слов $6 \cdot 4^3$;
- $k = 3$: подходят только позиции 1, 3, 5, слов $1 \cdot 4^2$;
- $k \ge 4$: невозможно — между каждой парой Л нужен хотя бы один разделитель, для четырёх Л потребуется минимум $4 + 3 = 7$ мест, а их только 5.

Случаи по $k$ не пересекаются и вместе покрывают все слова, поэтому их можно просто сложить. Итог — сумма по всем подходящим $k$.

## Разобранный пример

Считаем по четырём случаям.

1. Букв Л нет: $4^5 = 1024$.
2. Одна Л: 5 позиций и $4^4 = 256$ заполнений остальных мест → $5 \cdot 256 = 1280$.
3. Две Л: не соседних пар $10 - 4 = 6$, на три остальных места $4^3 = 64$ варианта → $6 \cdot 64 = 384$.
4. Три Л: только позиции 1, 3, 5, два оставшихся места дают $4^2 = 16$ вариантов → $16$.

Складываем: $1024 + 1280 + 384 + 16 = 2704$.

Проверка сложения: $1024 + 1280 = 2304$, $2304 + 384 = 2688$, $2688 + 16 = 2704$.

Ответ: 2704
## Типичные ошибки

1. **Вычли из $5^5$ все слова, где встречается «ЛЛ», считая пары отдельно.** В слове «ЛЛЛРТ» две пары «ЛЛ», и оно будет вычтено дважды. Как поймать: возьми такое слово и посчитай, сколько раз оно попало в вычитание; больше одного — способ не годится.

2. **Для двух Л взяли все 10 пар позиций.** Соседние пары 1–2, 2–3, 3–4, 4–5 запрещены. Как поймать: выпиши эти 4 пары и зачеркни, останется 6 пар.

3. **Забыли случай с тремя Л.** Кажется, что на 5 мест три Л не уложить. Как поймать: попробуй расставить их через одно место — получается 1, 3, 5; значит, нужно прибавить ещё 16 слов.

Тот же ответ даёт другая проверка — динамика по последней букве. Пусть $a_n$ — число подходящих слов длины $n$, оканчивающихся на Л, а $b_n$ — оканчивающихся на другую букву. Тогда

$a_{n+1} = b_n$ (Л можно дописать только после не-Л), $b_{n+1} = 4(a_n + b_n)$ (не-Л можно дописать после любой буквы, выборов 4).

Посчитаем: $n = 1$: $a = 1, b = 4$; $n = 2$: $a = 4, b = 20$; $n = 3$: $a = 20, b = 96$; $n = 4$: $a = 96, b = 464$; $n = 5$: $a = 464, b = 2240$. Итого $464 + 2240 = 2704$ — совпало с первым способом.

Два разных способа счёта, которые дали одно число, — хорошая проверка.
