# Разобраться: №16. Рекурсия

## Правило

Рекурсивная функция задана двумя частями: базой и шагом. База здесь $F(n) = n$ при $n < 4$, то есть $F(1) = 1$, $F(2) = 2$, $F(3) = 3$. Шаг: $F(n) = n + F(n - 2)$ при $n \ge 4$.

Шаг уменьшает аргумент на 2, поэтому чётность сохраняется: из нечётного $n$ получится цепочка нечётных чисел, из чётного — чётных. Не надо раскрывать $F(17)$ в одну длинную строку до самого низа: удобнее идти от базы вверх. Считаем $F(5) = 5 + F(3)$, затем $F(7) = 7 + F(5)$ и так далее — каждое новое значение использует уже найденное.

Можно сразу записать сумму:

$$F(n) = n + (n - 2) + (n - 4) + \ldots$$

Слагаемые идут до числа меньше 4: для нечётного $n$ это 3, для чётного — 2. Проверьте базу на первом же шаге: $F(4) = 4 + F(2) = 6$, а не просто 4. Это арифметическая прогрессия с разностью 2. Сумму считаем по числу слагаемых и среднему крайних: $S = k \cdot \dfrac{a_1 + a_k}{2}$.

## Разобранный пример

Шаг 1. Пишем цепочку для 17: $F(17) = 17 + F(15) = 17 + 15 + F(13) = \ldots$. Все числа нечётные, с каждым шагом минус 2.

Шаг 2. Последнее нечётное число перед базой — 3: $17 - 2 \cdot 7 = 3$. Дальше $F(3) = 3$, потому что $3 < 4$. Значит,

$$F(17) = 17 + 15 + 13 + 11 + 9 + 7 + 5 + 3.$$

Шаг 3. Слагаемых восемь, первое 17, последнее 3. Среднее равно $(17 + 3) : 2 = 10$, поэтому сумма $8 \cdot 10 = 80$.

Проверка снизу: $F(3) = 3$, $F(5) = 8$, $F(7) = 15$, $F(9) = 24$, $F(11) = 35$, $F(13) = 48$, $F(15) = 63$, $F(17) = 80$. Оба способа дали одно число.

Ответ: 80
## Типичные ошибки

1. **Дошли до $F(1)$ и прибавили лишнюю единицу.** База срабатывает уже на $F(3)$: цепочка $17, 15, \ldots, 3$ обрывается на 3. Как поймать: проверь, что $17 - 2k = 3$ при $k = 7$; следующее число 1 в этой цепочке не участвует.

2. **Подумали, что шаг уменьшает аргумент на 1, и вызвали $F(16)$.** В формуле стоит $F(n - 2)$, а не $F(n - 1)$. Как поймать: посмотри на чётность: 17 нечётное, значит, все числа в цепочке нечётные, и 16 там быть не может.

3. **Остановились на $F(5) = 5$, решив, что база — это $n < 5$.** В условии база $n < 4$. Как поймать: подставь $n = 5$ в шаг: $F(5) = 5 + F(3) = 8$, а не 5.

## Углубиться

<details>
<summary>Если осталось время и хочется разобраться глубже:</summary>

Для нечётного $n \ge 3$ цепочка состоит из нечётных чисел $3, 5, \ldots, n$. Сумма первых $k$ нечётных чисел равна $k^2$, а здесь $k = (n + 1) : 2$, причём число 1 в сумме отсутствует. Для $n = 17$: $(17 + 1) : 2 = 9$, значит $F(17) = 9^2 - 1 = 80$ — совпало с прямым счётом.

Для чётного $n$ цепочка состоит из чётных чисел $2, 4, \ldots, n$. Посмотрите, как меняется результат при переходе к следующему чётному числу: $F(6) = 6 + F(4) = 12$, $F(8) = 8 + F(6) = 20$. Шаг по-прежнему один и тот же, меняется только базовая ветка.

</details>
