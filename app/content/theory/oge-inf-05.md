# Разобраться: №5. Алгоритм для исполнителя

## Правило
У исполнителя есть несколько команд. Нужно составить цепочку команд, которая превратит начальное число в нужное. Длина цепочки ограничена, поэтому перебирать варианты вслепую долго.

Удобнее идти от конца. Смотри на последнее число и думай: какой командой оно могло получиться? Если последняя команда была «умножь на 3», то перед ней число ровно в 3 раза меньше. Если была «прибавь 2», то перед ней число на 2 меньше.

Проверяй оба варианта, но с оглядкой на команды. Делить на 3 имеет смысл только тогда, когда число делится на 3 без остатка. Вычитать 2 можно всегда. Так шаг за шагом возвращайся к начальному числу.

Когда дошёл до него, переверни список шагов. Получится алгоритм от начального числа к нужному. Обязательно посчитай цепочку ещё раз слева направо и проверь число команд: оно не должно превышать предел из условия.

Если есть несколько подходящих алгоритмов, можно записать любой. Главное — он должен работать и укладываться в лимит.

## Разобранный пример
Исполнитель Альфа: команда 1 — прибавь 2, команда 2 — умножь на 3. Из 7 нужно получить 621 не более чем за 5 команд.

Идём от конца:

1. 621 делится на 3: $621 : 3 = 207$. Значит, последней могла быть команда 2.
2. 207 делится на 3: $207 : 3 = 69$. Опять команда 2.
3. 69 делится на 3: $69 : 3 = 23$. Снова команда 2.
4. 23 на 3 не делится. Значит, здесь была команда 1: перед ней было $23 - 2 = 21$.
5. 21 делится на 3: $21 : 3 = 7$. Получили начальное число.

Переворачиваем шаги: 7 → 21 → 23 → 69 → 207 → 621. Номера команд: 2, 1, 2, 2, 2. Проверим по шагам:

- $7 \cdot 3 = 21$ — команда 2;
- $21 + 2 = 23$ — команда 1;
- $23 \cdot 3 = 69$ — команда 2;
- $69 \cdot 3 = 207$ — команда 2;
- $207 \cdot 3 = 621$ — команда 2.

Команд ровно 5, результат верный.

Ответ: 21222

## Типичные ошибки
- Начинают с команды 1: 7 + 2 = 9, дальше 9 · 3 = 27, и цепочка не приводит к цели за 5 шагов. Поймать: иди от конца, а не от начала — так выбор последней команды сразу виден по делимости на 3.
- Пытаются разделить 23 на 3 и получают дробь. Поймать: перед делением проверь остаток. 23 не делится на 3, значит, последним был «прибавь 2», и нужно вычесть 2.
- Записывают верные числа, но путают порядок команд. Поймать: переверни список шагов и обязательно прогони его слева направо, сверя каждое число с цепочкой выше.

## Углубиться
<details>
<summary>Если осталось время и хочется разобраться глубже:</summary>
Движение от конца удобно тем, что у каждой команды есть обратная. Для «прибавь 2» обратная — «вычти 2». Для «умножь на 3» обратная — «раздели на 3», но только когда число делится без остатка.

Из-за этого шаги назад иногда ветвятся: подходят сразу два варианта. Тогда пробуй оба и смотри, какой быстрее приведёт к начальному числу. Здесь деление на 3 работало почти всегда, и только на числе 23 пришлось вычесть 2.

Ещё полезно считать команды в обратном списке. Мы нашли 5 шагов назад — значит, и вперёд их будет столько же. Лимит в 5 команд соблюдён.
</details>
