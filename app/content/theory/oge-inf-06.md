# Разобраться: №6. Анализ программы с условием

## Правило
В этом номере нужно по коду понять, при каких входных данных программа печатает `YES`, а при каких — `NO`. Главное — внимательно прочитать условие `if`.

Если в условии стоит `or` (логическое «ИЛИ»), результат будет истинным, когда выполняется хотя бы одно из условий. Для `NO` нужны оба ложных условия сразу.

Если бы стояло `and` (логическое «И»), было бы наоборот: для `YES` должны выполняться оба условия.

Алгоритм простой:
1. Выпиши условие из `if`.
2. Для каждой пары входных чисел подставь значения и проверь каждую часть отдельно.
3. Объедини части через `or` или `and`.
4. Отметь, что напечатает программа: `YES` или `NO`.
5. Посчитай, сколько раз получился нужный ответ.

Удобно делать маленькую таблицу: пара чисел, первая проверка, вторая проверка, итог.

## Разобранный пример
Дана программа:

```python
s = int(input())
t = int(input())
if s > 3 or t > 8:
    print("YES")
else:
    print("NO")
```

Было 9 запусков со входными парами: (6, 5), (7, 1), (0, 8), (14, 7), (7, 5), (4, -1), (6, 8), (10, 2), (9, -2). Нужно узнать, сколько раз программа напечатала `YES`.

Проверяем условие `s > 3 or t > 8` для каждой пары:

| Пара | $s > 3$ | $t > 8$ | Итог | Вывод |
|---|---|---|---|---|
| (6, 5) | да | нет | да | YES |
| (7, 1) | да | нет | да | YES |
| (0, 8) | нет | нет | нет | NO |
| (14, 7) | да | нет | да | YES |
| (7, 5) | да | нет | да | YES |
| (4, -1) | да | нет | да | YES |
| (6, 8) | да | нет | да | YES |
| (10, 2) | да | нет | да | YES |
| (9, -2) | да | нет | да | YES |

Обрати внимание на пару (0, 8): $t > 8$ ложно, потому что 8 не больше 8. Строгое неравенство не включает саму границу.

`YES` получился в 8 случаях из 9.

Ответ: 8

## Типичные ошибки
- Считают, что $8 > 8$ истинно. На самом деле знак $>$ строгий: равенство не подходит. Поймать: подставь граничное число и прочитай знак вслух — «строго больше» или «больше или равно».
- Путают `or` и `and`. При `or` достаточно одного истинного условия, а при `and` нужны оба. Поймать: для `or` спроси себя «хотя бы одно верно?», для `and` — «оба верны?».
- Проверяют только одну переменную и забывают вторую часть условия. Поймать: разбивай `if` на отдельные проверки и заполняй таблицу по столбцам.

## Углубиться
<details>
<summary>Если осталось время и хочется разобраться глубже:</summary>
Полезно помнить связь условий с отрицанием. Программа печатает `NO`, когда условие `s > 3 or t > 8` ложно. Для `or` это значит, что ложны обе части: $s \le 3$ и $t \le 8$.

Это тот же приём, который помогает быстро проверять ответ: вместо того чтобы искать все `YES`, можно найти только `NO`. В примере такая пара одна — (0, 8), значит, `YES` будет $9 - 1 = 8$.

Приём «посчитать противоположное» часто экономит время, особенно когда нужных запусков много.
</details>
