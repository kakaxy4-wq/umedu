# Разобраться: №7. Адрес файла в интернете

## Правило
Адрес файла в интернете (URL) собирается в строгом порядке. Для школьных задач достаточно запомнить схему:

$$\text{протокол} + \text{://} + \text{сервер} + \text{/} + \text{имя файла}$$

Например: `http://home.ru/report.doc`.

Разберём части:
- **протокол** — способ передачи, обычно `http` или `https`;
- **://** — разделитель после протокола;
- **сервер** — имя сайта или домена, например `home.ru`;
- **/** — разделитель перед именем файла;
- **имя файла** — сам файл с расширением, например `report.doc`.

В задании части адреса перемешаны и закодированы буквами. Твоя задача — не угадывать, а собрать полный адрес по схеме, а потом заменить каждую часть на её букву.

Удобно сначала записать готовый адрес обычным текстом, затем разрезать его на фрагменты из таблицы и только потом выписать код.

## Разобранный пример
Доступ к файлу **report.doc** на сервере **home.ru** осуществляется по протоколу **http**. Фрагменты адреса закодированы буквами:

| Буква | Фрагмент |
|---|---|
| А | http |
| Б | .doc |
| В | .ru |
| Г | report |
| Д | / |
| Е | :// |
| Ж | home |

Шаг 1. Собираем адрес по схеме: протокол + `://` + сервер + `/` + файл.

Протокол — `http`, сервер — `home.ru`, файл — `report.doc`. Получаем:

`http://home.ru/report.doc`

Шаг 2. Разбиваем адрес на фрагменты из таблицы:

- `http` — А
- `://` — Е
- `home` — Ж
- `.ru` — В
- `/` — Д
- `report` — Г
- `.doc` — Б

Шаг 3. Записываем буквы по порядку: А, Е, Ж, В, Д, Г, Б.

Ответ: АЕЖВДГБ

## Типичные ошибки
- Ставят имя файла перед сервером или путают порядок частей. Поймать: сначала запиши полный адрес одной строкой, а уже потом кодируй его по буквам.
- Забывают разделитель `://` или пишут только `:`. Поймать: сверяйся со схемой — после протокола всегда идёт `://`, а перед файлом отдельный `/`.
- Склеивают сервер неправильно, например теряют `.ru`. Поймать: проверь, что из выбранных фрагментов домен собирается целиком: `home` + `.ru` = `home.ru`.

## Углубиться
<details>
<summary>Если осталось время и хочется разобраться глубже:</summary>
Иногда в адресе встречаются дополнительные части: порт после сервера (`:8080`) или папки перед файлом (`/docs/2026/report.doc`). Схема при этом остаётся той же: сначала протокол и сервер, потом путь к файлу.

Если видишь незнакомый фрагмент, не гадай, куда его поставить. Найди его место в готовом адресе: серверная часть идёт до первого одиночного `/` пути, а всё после него — путь к файлу.

В задачах ОГЭ обычно дают простую форму без портов и вложенных папок, поэтому достаточно уверенно собрать базовую схему.
</details>
