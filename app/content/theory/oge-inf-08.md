# Разобраться: №8. Запросы к поисковой системе

## Правило
В запросах поисковика в этом номере встречаются две операции:
- `|` — «ИЛИ»: страница подходит, если на ней есть первое слово, второе или оба.
- `&` — «И»: страница подходит, только если на ней есть оба слова сразу.

Удобно представлять запросы как два круга, которые пересекаются. Один круг — страницы со словом А, другой — со словом Б. Пересечение — страницы, где есть оба слова.

Главная формула:

$$|A \mid B| = |A| + |B| - |A \,\&\, B|$$

Почему вычитаем пересечение? Потому что при сложении $|A| + |B|$ страницы, где есть оба слова, посчитаны два раза. Один раз их нужно убрать.

Если в задаче неизвестно пересечение, формулу можно перевернуть:

$$|A \,\&\, B| = |A| + |B| - |A \mid B|$$

Перед вычислением проверь, что все числа в одной единице — обычно в тысячах страниц.

## Разобранный пример
В таблице даны запросы и количество найденных страниц:

| Запрос | Найдено страниц (в тысячах) |
|---|---|
| Фрегат \| Эсминец | ? |
| Фрегат & Эсминец | 808 |
| Фрегат | 1236 |
| Эсминец | 2083 |

Нужно найти количество страниц по запросу «Фрегат | Эсминец».

Шаг 1. Определяем, что известно: $|Фрегат| = 1236$, $|Эсминец| = 2083$, $|Фрегат \,\&\, Эсминец| = 808$.

Шаг 2. Нужен запрос с `|`, значит, используем формулу:

$$|Фрегат \mid Эсминец| = |Фрегат| + |Эсминец| - |Фрегат \,\&\, Эсминец|$$

Шаг 3. Подставляем числа:

$$|Фрегат \mid Эсминец| = 1236 + 2083 - 808 = 2511$$

Проверка по смыслу: результат должен быть не меньше каждого круга по отдельности и не больше их суммы. $2511 \ge 2083$ и $2511 \le 3319$ — всё нормально.

Ответ: 2511

## Типичные ошибки
- Складывают два круга и забывают вычесть пересечение. Получается 3319, но общие страницы посчитаны дважды. Поймать: проверь формулу — в ней для `|` всегда есть минус пересечение.
- Путают `|` и `&` и вычитают не то значение. Поймать: проговори операцию словами: «ИЛИ» — шире, «И» — уже, поэтому результат для `|` обычно больше.
- Ошибаются в арифметике при сложении и вычитании больших чисел. Поймать: сделай быстрый контроль — ответ для `|` не может быть меньше большего из двух запросов.

## Углубиться

<summary>Если осталось время и хочется разобраться глубже:</summary>
Ту же задачу можно решить через части кругов. Пусть только «Фрегат» — это $1236 - 808 = 428$, только «Эсминец» — $2083 - 808 = 1275$, а пересечение — $808$. Тогда запрос «Фрегат | Эсминец» покрывает все три части: $428 + 808 + 1275 = 2511$.

Этот способ дольше, но хорошо показывает, откуда берётся формула. Если сомневаешься в знаке, нарисуй два круга и подпиши каждую область — ошибка сразу станет заметной.
</details>
