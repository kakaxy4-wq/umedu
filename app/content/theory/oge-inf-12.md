# Разобраться: №12. Поиск файлов по маске

## Правило
Маска — это шаблон имени файла. Нужно понять, какие имена из списка под шаблон подходят, и посчитать их.

Помнят два символа:
- `?` означает ровно один произвольный символ — не больше и не меньше;
- `*` означает любую последовательность символов произвольной длины, в том числе пустую.

Маска проверяется по всему имени целиком, включая точку и расширение. Если в маске написано `?*.tex`, то:
- первым символом должен быть какой-то один символ (не пусто);
- дальше может быть что угодно, хоть ничего (`*`);
- в конце обязательно стоит `.tex`.

Удобно проверять каждый файл по частям. Сначала смотришь конец: заканчивается ли на `.tex`. Потом начало: есть ли хотя бы один символ перед точкой. Если оба условия выполнены — файл подходит, остальные символы не важны.

Не путай `?` и `*`. Один `?` не может заменить два символа, а `*` спокойно заменяет и один, и десять, и ноль символов. Например, маске `?*.tex` подойдёт `a.tex`, но не подойдёт `.tex` — там перед точкой нет ни одного символа.

Ответ — количество подходящих файлов, целое число.

## Разобранный пример
Для групповых операций с файлами используются маски имён файлов: символ «?» означает ровно один произвольный символ, «*» — любую последовательность символов произвольной длины, в том числе пустую. Сколько файлов из списка ниже удовлетворяет маске `?*.tex`?

aaoo.dat
aoac.doc
aoaoac.dot
bbooac.tex
boa.dot
coc.tex
oac.doc
obcbcb.dot
oboob.tex

Шаг 1. Отберём файлы с окончанием `.tex`: `bbooac.tex`, `coc.tex`, `oboob.tex`. Остальные заканчиваются на `.dat`, `.doc` или `.dot`, поэтому сразу не подходят.

Шаг 2. Проверим начало каждого из трёх. У `bbooac.tex` перед точкой стоит `bbooac` — первый символ `b` есть, значит `?` его заменяет, а `*` закрывает остальные пять букв. Подходит.

Шаг 3. У `coc.tex` перед точкой `coc`: первый символ `c`, остальные `oc` — снова `?` плюс `*`. Подходит.

Шаг 4. У `oboob.tex` перед точкой `oboob`: первый символ `o`, остальное закрывает `*`. Подходит.

Шаг 5. Посчитаем: подходящих файлов три. Обратно сверься со списком: файлов с `.tex` больше нет.

Ответ: 3

## Типичные ошибки
- Считают, что `?` заменяет любое число символов. Поймать: подставь в позицию `?` ровно одну букву и посмотри, осталась ли ещё часть имени для `*`; если имя состоит только из расширения, файл не подходит.
- Проверяют только расширение и забывают про начало маски. Поймать: для каждого кандидата явно покажи первый символ перед точкой — его должен быть можно указать пальцем.
- Пропускают файл при пересчёте. Поймать: отметь подходящие имена в списке галочками и посчитай галочки, а не «на глаз».

## Углубиться
<details>
<summary>Если осталось время и хочется разобраться глубже:</summary>
Маску можно нарисовать как цепочку: `?` — одна клетка, `*` — резинка, которая растягивается на любое число клеток. Тогда `?*.tex` читается так: «одна буква, потом что угодно, потом точка и tex».

Если бы маска была `*.tex`, подошёл бы даже файл с именем `.tex` (если такое разрешено условием), потому что `*` может быть пустой. А в нашем случае пустое начало не годится: `?` всё равно требует один символ. Именно эта маленькая разница чаще всего меняет ответ.
</details>
