# Разобраться: №14. Электронная таблица

## Правило
В таблице каждая строка — одна запись, а столбцы хранят её признаки: товар, магазин, цена. Нужно выбрать строки по признаку и сложить числа из нужного столбца.

Работай по шагам. Сначала прочитай вопрос и выпиши условие отбора, например «магазин Мост». Затем проходи по строкам сверху вниз и смотри только на столбец «Магазин». Если значение совпало, бери число из столбца «Цена, руб.» и записывай его в отдельный столбик. Если нет — пропускай строку целиком.

Когда все подходящие цены выписаны, сложи их. Чтобы не ошибиться, складывай парами или проверяй сумму вторым проходом: посчитай ещё раз в другом порядке (например, снизу вверх) и сравни результат.

В ответе пиши число в рублях, без слова «руб.» — в условии уже сказано, в чём мера. Но если просят «ответ дай в рублях», число должно быть именно суммой цен, а не количеством строк.

Важно не путать столбцы: цена всегда берётся из колонки «Цена, руб.», а не из названия товара. И не складывай все строки подряд — отбор по магазину обязателен.

## Разобранный пример
В таблице покупки за неделю. Чему равна сумма цен товаров из магазина «Мост»? Ответ дай в рублях.

| Товар | Магазин | Цена, руб. |
| --- | --- | --- |
| карандашей | Юг | 123 |
| карандашей | Север | 398 |
| тетрадей | Север | 214 |
| марок | Мост | 321 |
| карандашей | Юг | 77 |
| открыток | Мост | 61 |
| карандашей | Север | 347 |
| яблок | Мост | 399 |
| марок | Север | 225 |
| марок | Юг | 167 |
| тетрадей | Мост | 268 |
| яблок | Юг | 128 |
| яблок | Мост | 258 |
| карандашей | Юг | 350 |
| марок | Мост | 40 |
| яблок | Север | 139 |

Шаг 1. Отберём строки, где в столбце «Магазин» стоит «Мост»:
- марки — 321;
- открытки — 61;
- яблоки — 399;
- тетради — 268;
- яблоки — 258;
- марки — 40.

Шаг 2. Сложим выписанные цены по порядку:

$$321 + 61 = 382$$
$$382 + 399 = 781$$
$$781 + 268 = 1049$$
$$1049 + 258 = 1307$$
$$1307 + 40 = 1347$$

Шаг 3. Проверим в обратном порядке: $40 + 258 = 298$, $298 + 268 = 566$, $566 + 399 = 965$, $965 + 61 = 1026$, $1026 + 321 = 1347$. Совпало.

Шаг 4. Убедимся, что строк с «Мост» больше нет: в таблице 16 строк, отобрали 6, остальные относятся к «Юг» и «Север».

Ответ: 1347

## Типичные ошибки
- Складывают цены всех строк, забывая про отбор по магазину. Поймать: перед сложением обведи в каждой взятой строке слово «Мост» — если его нет, строка не участвует.
- Берут число из столбца «Товар» или путают строки с одинаковым товаром. Поймать: пальцем веди по строке от «Магазин» до «Цена, руб.», не перескакивая в соседнюю строку.
- Теряют одну цену при сложении. Поймать: посчитай сумму дважды — сверху вниз и снизу вверх — и сравни; расхождение укажет на пропуск.

## Углубиться

<summary>Если осталось время и хочется разобраться глубже:</summary>
В реальной таблице такую задачу решают формулой суммирования по условию: она проверяет столбец магазина и складывает только подходящие ячейки цены. Но ручная проверка всё равно нужна — формулу легко написать с опечаткой.

Ещё одна полезная привычка: оценить ответ заранее. У нас шесть цен, каждая примерно от 40 до 400, значит сумма должна быть вокруг тысячи. Получив 1347, видим, что порядок верный; получив 134 или 13470, сразу искали бы ошибку.
