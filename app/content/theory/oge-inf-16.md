# Разобраться: №16. Программа на Python

## Правило
В этом номере программа получает числа до нуля. Ноль — признак окончания ввода, в последовательность он не входит. Значит, заранее неизвестно, сколько чисел будет, и нельзя писать цикл `for range(...)`, где число повторов задано заранее.

Используют цикл `while`. Типичная схема:

```
s = 0
x = int(input())
while x != 0:
    if <условие>:
        s += x
    x = int(input())
print(s)
```

Важные детали:
- переменную суммы $s$ создают **до** цикла и обнуляют;
- первое число вводят до цикла, чтобы условие `x != 0` можно было проверить;
- внутри цикла обязательно снова вводят число — иначе цикл не завершится;
- ноль не прибавляют к сумме: он только останавливает ввод.

Двузначные числа — это целые числа от 10 до 99 включительно. Проверка в Python пишется цепочкой: `10 <= x <= 99`. Она читается естественно: «$x$ не меньше 10 и не больше 99». Можно записать и через `and`, но цепочка короче.

В конце выводят только сумму: `print(s)`. Лишние подписи в выводе не нужны — проверяющая система ждёт одно число.

## Разобранный пример
Напишите программу, которая в последовательности натуральных чисел определяет сумму двузначных чисел.

Программа получает на вход натуральные числа, количество введённых чисел неизвестно, последовательность чисел заканчивается числом 0 (0 — признак окончания ввода, не входит в последовательность). В последовательности всегда имеется хотя бы одно число. Количество чисел, не считая 0, не превышает 1000. Введённые числа не превышают 30000.

Программа должна вывести одно число — сумму двузначных чисел.

Программа:

```python
s = 0
x = int(input())
while x != 0:
    if 10 <= x <= 99:
        s += x
    x = int(input())
print(s)
```

Разбор по шагам.

Шаг 1. До цикла $s = 0$: пока не сложено ни одного числа. Вводим первое $x$.

Шаг 2. Проверяем `x != 0`. Если введён ноль, цикл не начнётся и выведется 0 — это верно, потому что подходящих чисел не было. Иначе идём внутрь.

Шаг 3. Условие `10 <= x <= 99` отделяет двузначные. Например, 9 не подходит, 10 подходит, 99 подходит, 100 не подходит. Если подходит — прибавляем к $s$.

Шаг 4. В конце тело цикла снова считывает число. Благодаря этому цикл обрабатывает всю последовательность и останавливается на нуле.

Шаг 5. Проверим на вводе `5, 12, 100, 30, 0`: подходящие 12 и 30, сумма $12 + 30 = 42$. Программа выведет 42 — совпадает с ручным счётом.

Ответ: программа выше; она выводит сумму двузначных чисел (например, для 5, 12, 100, 30, 0 — 42)

## Типичные ошибки
- Забывают второй `input()` внутри цикла. Поймать: посмотри, меняется ли $x$ за один проход; если нет, цикл будет бесконечным.
- Прибавляют к сумме ноль или считают его двузначным. Поймать: прочитай условие ещё раз — ноль только признак конца, проверка `x != 0` стоит до тела цикла.
- Пишут условие `x > 10 and x < 99` и теряют 10 и 99. Поймать: проверь границы отдельно — 10 и 99 двузначные, значит знаки должны быть нестрогими: `10 <= x <= 99`.

## Углубиться
<details>
<summary>Если осталось время и хочется разобраться глубже:</summary>
Та же схема подходит для любой проверки числа: сумма чётных, количество трёхзначных, произведение нечётных. Меняется только условие внутри `if`, а каркас с вводом до цикла и повторным вводом в конце остаётся тем же.

Если бы нужно было не складывать, а считать подходящие числа, вместо `s += x` писали бы `s += 1`. Начальное значение всё равно ноль — это удобная привычка для задач на сумму и количество.
</details>
