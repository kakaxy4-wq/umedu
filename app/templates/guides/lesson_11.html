1. План по шагам

ШагЧто делаем
1(15 мин) Рисуем на бумаге схему квеста: сцены и стрелки-выборы.
2(15 мин) Каждая сцена — функция, выбор вызывает другую функцию.
3(35 мин) Пишем первые 3–4 сцены, переменные «здоровье» и «инвентарь».
4(5 мин) Итог.

Правило урока: код пишет ученик, ты помогаешь вопросами. Наводящие вопросы вместо готовых ответов.

2. Ключевые темы

  • Блок-схема

  • Инвентарь и здоровье

Разбери пример «Скелет квеста» по строкам:

inventory = []

def start():
    print("Ты стоишь у входа в пещеру. Рядом лежит факел.")
    choice = input("1 — взять факел, 2 — войти без него: ")
    if choice == "1":
        inventory.append("факел")
    cave()

def cave():
    if "факел" in inventory:
        print("Факел освещает сундук с золотом! Победа 🏆")
    else:
        print("Темно... Ты споткнулся и вернулся домой. Конец.")
