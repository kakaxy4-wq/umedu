2. Ключевые темы

  • Срезы `s[::-1]`
  • Методы `upper`, `lower`, `replace`, `split`, `count`
  • Проверка пароля

Разбери пример «Палиндром» по строкам:

phrase = "А роза упала на лапу Азора"
clean = phrase.lower().replace(" ", "")
print(clean)
print(clean[::-1])
print("Палиндром!" if clean == clean[::-1] else "Не палиндром")
