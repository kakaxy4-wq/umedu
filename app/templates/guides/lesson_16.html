2. Ключевые темы

  • Словари `{}`
  • `get`, `items()`
  • Частотный анализ

Разбери пример «Частота букв» по строкам:

text = "кто рано встаёт тому бог подаёт"
count = {}
for ch in text:
    if ch != " ":
        count[ch] = count.get(ch, 0) + 1
for ch, n in sorted(count.items(), key=lambda p: -p[1])[:5]:
    print(ch, "█" * n)
