Разбери пример «JSON» по строкам:

import json
hero = {"имя": "Рыцарь", "уровень": 3, "инвентарь": ["меч", "щит"]}
text = json.dumps(hero, ensure_ascii=False, indent=2)
print(text)
back = json.loads(text)
print(back["инвентарь"][0])
