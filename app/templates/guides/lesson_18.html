2. Ключевые темы

  • Состояние программы в словаре
  • Сохранение в JSON
  • Время между запусками

Разбери пример «Основа тамагочи» по строкам:

pet = {"имя": "Байт", "сытость": 5, "настроение": 5}

def show():
    face = "(^_^)" if pet["настроение"] > 3 else "(-_-)"
    print(face, pet)

for action in ["кормить", "играть", "играть"]:
    if action == "кормить":
        pet["сытость"] = min(10, pet["сытость"] + 3)
    elif action == "играть":
        pet["настроение"] += 2
        pet["сытость"] -= 1
    show()
