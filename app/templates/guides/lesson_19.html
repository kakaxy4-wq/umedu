2. Ключевые темы

  • `pygame`
  • Игровой цикл: события → обновление → отрисовка
  • FPS

Разбери пример «Прыгающий мяч» по строкам:

import pygame
pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()
x, y, dx, dy = 400, 300, 5, 4
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    x += dx
    y += dy
    if x < 20 or x > 780:
        dx = -dx
    if y < 20 or y > 580:
        dy = -dy
    screen.fill((20, 20, 40))
    pygame.draw.circle(screen, (255, 200, 0), (x, y), 20)
    pygame.display.flip()
    clock.tick(60)
pygame.quit()
