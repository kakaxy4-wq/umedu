2. Типы данных, // и %

«У каждого значения в Python есть тип — как у предметов в рюкзаке: тетради, ручки, яблоки. С разными типами можно делать разное: яблоко можно съесть, а тетрадь — нет.»

ТипЧто этоПримерыЧто с ним можно
intцелое число (от англ. integer — целый)7, -3, 2026считать, сравнивать
floatдробное число (от floating point — «плавающая точка»)3.5, 0.1, -2.0считать (дробная часть — через точку, не запятую!)
strстрока, текст (от string — строка, нитка)"кот", "7", ""склеивать, повторять, искать буквы

Покажи type(): print(type(7)), print(type("7")), print(type(7 / 1)). И превращения: int("12") → 12, str(12) → "12", float("2.5") → 2.5.

Вау-момент: компьютер ошибается в арифметике?

print(0.1 + 0.2)

Спроси сначала: «Сколько будет?» — 0.3, конечно. А Python напишет 0.30000000000000004.

«Компьютер хранит числа в двоичной системе — только нулями и единицами. Число 0,1 в двоичной системе — бесконечная дробь, как 1/3 = 0,3333… у нас. Компьютер её обрезает, и появляется крошечная ошибка. Поэтому деньги в программах часто считают в копейках — целыми числами.»

Делим конфеты: // и %

Высыпи 47 конфет (монеток, спичек) и предложи разделить поровну на 5 человек. Пусть ученик раскладывает руками, а потом проверит Python:

candies = 47
kids = 5
print("Каждому:", candies // kids)
print("Останется:", candies % kids)

Где в жизни прячется остаток

🕒

Часы. Сейчас 22:00, через 5 часов будет (22 + 5) % 24 = 3 часа ночи. Циферблат — это и есть остаток.

⚖️

Чётное или нечётное. Число чётное, если n % 2 равно 0. Так игры решают, чей ход.

🔢

Последняя цифра: 2026 % 10 = 6. А 2026 // 10 = 202 — число без последней цифры.

📅

Дни недели. Если сегодня понедельник, то через 100 дней — 100 % 7 = 2 дня вперёд, то есть среда.

3. Охота на баги

«У программистов ошибки бывают каждый день — у новичков и у самых крутых. Разница в одном: опытный программист читает сообщение об ошибке, а новичок пугается. Сегодня научимся читать.»

5 программ с ошибками — скопируй в песочницу заранее

Давай по одной. Ученик запускает, читает ошибку вслух («где, что, подсказка»), чинит. Не подсказывай сразу — дай 1–2 минуты подумать.

ПрограммаОшибкаКак починить
prnt("Привет")NameErrorОпечатка: print. Python не знает слова, которого нет.
print("Привет)SyntaxErrorКавычка не закрыта — Python не понял, где кончается текст.
age = 13
print("Мне " + age)		TypeErrorНельзя склеить текст и число: str(age) или запятая в print.
n = int("пять")ValueErrorint() понимает только цифры. Ввод «пять» вместо 5 — ошибка пользователя.
print(10 / 0)ZeroDivisionErrorНа ноль делить нельзя — и в математике, и в Python.

Бонус: пример «Найди и исправь ошибку» из урока — там три ошибки сразу. Python показывает только первую: починил — запусти снова — увидишь следующую. Так и работают программисты.

Цена одной ошибки — истории для рассказа

  • «Фобос-1» (1988). Советская станция летела к Марсу и его спутнику Фобосу. В одной из команд, переданных с Земли, оказалась ошибка — и станция отключила систему ориентации. Солнечные батареи отвернулись от Солнца, и связь с аппаратом потеряли. Одна неверная строчка — и межпланетная станция потеряна.
  • «Ариан-5» (1996). Европейская ракета взорвалась через 37 секунд после первого старта. Программа пыталась уложить большое дробное число (float) в маленькую ячейку для целых чисел — получилось переполнение, и компьютер ракеты сошёл с ума. Ошибка типов — ровно то, что мы сегодня разбираем.

💡 Вывод для ученика: ошибка — нормальная часть работы. Важно не «не ошибаться», а уметь найти и починить. Поэтому на сайте есть достижение «Победил баг».

4. Практика: задачи на сайте

Задачи под уроком проверяются автоматически. Твоя роль — не давать ответ, а задавать наводящие вопросы. Подсказка на сайте появляется после двух неудачных попыток.

ЗадачаНаводящий вопросКлюч
🐞 Охота на баги«Что Python пишет в последней строке?»три ошибки: imput, prnt, скобка, плюс int()
⏱️ Калькулятор времени«Сколько минут в часе? Сколько целых часов в 125 минутах?»m // 60 и m % 60
🔢 Разбери число«Как получить последнюю цифру? А без последней цифры?»n // 10 и n % 10
🍕 Сколько пиццы«Если нужно 9 кусков, хватит одной пиццы? А 17?»округление вверх: (x + 7) // 8
🎯 Выстрелы до победы«Если у врага 10 hp (очков здоровья), а выстрел снимает 3, — хватит 3 выстрелов?»(hp + dmg - 1) // dmg
