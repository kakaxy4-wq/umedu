2. Ключевые темы

  • `class`, `__init__`, `self`
  • Методы `update` и `draw`
  • Наследование

Разбери пример «Бой двух бойцов» по строкам:

import random

class Brawler:
    def __init__(self, name, hp, damage):
        self.name = name
        self.hp = hp
        self.damage = damage

    def attack(self, other):
        hit = random.randint(self.damage // 2, self.damage)
        other.hp = max(0, other.hp - hit)
        print(f"{self.name} бьёт {other.name} на {hit}, у него осталось {other.hp}")

a = Brawler("Питоша", 3000, 900)
b = Brawler("Тёртл", 3600, 700)
while a.hp > 0 and b.hp > 0:
    a.attack(b)
    if b.hp > 0:
        b.attack(a)
print("Победил", a.name if a.hp > 0 else b.name, "🏆")
