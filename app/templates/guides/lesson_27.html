2. Ключевые темы

  • Что такое API
  • `requests.get`
  • Разбор JSON-ответа

Разбери пример «Погода (на компьютере)» по строкам:

import requests
url = "https://api.open-meteo.com/v1/forecast"
params = {"latitude": 55.75, "longitude": 37.62, "current_weather": True}
data = requests.get(url, params=params).json()
w = data["current_weather"]
print("Температура:", w["temperature"], "°C")
print("Ветер:", w["windspeed"], "км/ч")
