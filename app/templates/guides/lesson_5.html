Цель урока

Ученик умеет создать свою команду через def, передать ей параметры и вызвать много раз с разными значениями. Понимает разницу между «функция что-то делает» (рисует, печатает) и «функция что-то возвращает» (return). Получает первое знакомство со случайными числами — и рисует звёздное небо одной функцией.

10 мин

1. Разбор домашки

Домашка урока 4 — свой узор с циклом в цикле. Пусть ученик покажет и объяснит: какой цикл внутренний, какой внешний, почему узор замкнулся (или не замкнулся).

Спроси: «Если я хочу на одном рисунке три мандалы в разных местах и разного размера — что придётся сделать?» Ответ: скопировать цикл три раза и поменять числа. «А можно научить Python слову “мандала”, чтобы писать одну строку?» — это и есть тема урока.

💡 Прими домашку в «📬 Проверка». Если сделана спираль-радуга — похвали за colors[i % 6].

15 мин

2. Функция — это рецепт

«Рецепт блинов записывают один раз, а готовят по нему сколько угодно. Функция — рецепт для компьютера: один раз объясняем, что значит “квадрат”, дальше просто говорим “квадрат!”.»

Ловушка-вопрос: напиши только def square(size): … без вызова и запусти. «Почему ничего не нарисовалось?» — рецепт записали, а готовить не стали. Это самая частая ошибка урока, пусть ученик споткнётся о неё сам.

25 мин

3. Несколько параметров: улица из домиков

Домик из урока 3 превращаем в функцию house(x, y, size): перелететь в точку (x, y) с поднятым пером, нарисовать стены-квадрат и крышу-треугольник размера size.

import turtle
t = turtle.Turtle()
t.speed(0)

def house(x, y, size):
    t.penup()
    t.goto(x, y)
    t.pendown()
    for i in range(4):          # стены
        t.forward(size)
        t.left(90)
    t.left(90)                  # к верхнему левому углу
    t.forward(size)
    t.right(30)                 # крыша — треугольник со стороной size
    t.forward(size)
    t.right(120)
    t.forward(size)
    t.left(60)                  # снова смотрим вправо

for i in range(5):
    house(-300 + i * 120, -50, 40 + i * 15)

Задание ученику: сначала вызвать house вручную 2–3 раза с разными числами, потом — в цикле, чтобы домики росли. Пусть сам подберёт формулу для x, чтобы домики не наезжали друг на друга.

💡 Порядок параметров важен: house(-300, -50, 40) и house(40, -50, -300) — совсем разные вызовы. Спроси, что нарисует второй (домик с отрицательным размером «вывернется» в другую сторону).

Задача на сайте: «Функция-звезда» — star(size). Сайт сам вызовет её с разными размерами и проверит, что нарисовано 5 линий нужной длины.

4. Функция, которая отвечает: return

Три задачи урока на сайте («Первая функция», «Чётное?», «Максимум из трёх») просят не нарисовать, а вернуть результат. В плане урока этого нет — объясни коротко здесь.

«Бывают функции-исполнители: нарисуй, напечатай. А бывают функции-калькуляторы: спросил — получил ответ и можешь с ним дальше работать.»

def double(x):
    return x * 2

a = double(4)        # a = 8
print(double(a))     # 16

5. random: звёздное небо

Покажи пример «Звёздное небо» на странице урока — вау-момент: 60 звёзд в случайных местах, каждый запуск — новое небо.

Факты к уроку — 2–3 на выбор

  • Подпрограммы (1949–1951). На английском компьютере EDSAC в Кембридже Дэвид Уилер придумал, как вызывать готовый кусок программы и возвращаться обратно. Такие куски назвали подпрограммами — это и есть предки функций. Библиотеку подпрограмм EDSAC описали в одной из первых книг о программировании (1951).
  • Случайность в компьютере не совсем случайна. random в Python вычисляет следующее «случайное» число по формуле из предыдущего — это генератор псевдослучайных чисел (алгоритм «вихрь Мерсенна», 1997, японские математики Мацумото и Нисимура). Если задать стартовое число — random.seed(42) — последовательность будет одинаковой при каждом запуске. Попробуйте!
  • Сид в Minecraft. Тот же принцип: мир Minecraft строится из одного числа — сида. Одинаковый сид — одинаковые горы и пещеры у всех игроков. Если ученик играет — отличный мостик.
  • print и input — тоже функции. Ученик пользуется функциями с первого урока, просто их написали за него. Сегодня он впервые делает свою.
