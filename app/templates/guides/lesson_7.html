2. Сравнения и первое if

«Каждое сравнение — это вопрос, на который компьютер отвечает только “да” (True) или “нет” (False).»

ЗаписьЧитаемПример → ответ
==равно?5 == 5 → True
!=не равно?5 != 3 → True
<, >меньше? больше?2 > 7 → False
<=, >=не больше? не меньше?18 >= 18 → True

Игра «Да или нет»: говоришь сравнение вслух («7 больше 3?», «10 не равно 10?»), ученик поднимает карточку ДА/НЕТ. Потом наоборот — ученик придумывает, ты отвечаешь (и иногда ошибаешься нарочно).

⚠️ Главная ловушка: = — «положи в коробку», == — «равно ли?». if age = 18: — это SyntaxError. Скажи: «Один знак — действие, два — вопрос».

4. «Угадай число» с одной попытки

Пример «Угадай с одной попытки»: random.randint(1, 10) из урока 5 + одно условие. Вау-момент — компьютер «загадал» и честно сказал число.

Задание ученику: добавить подсказку — если не угадал, сказать «больше» или «меньше». Нужен elif. Это заготовка к уроку 8, где попыток станет много.

import random
secret = random.randint(1, 10)
guess = int(input("Я загадал число от 1 до 10. Какое? "))
if guess == secret:
    print("Невероятно! Угадал!")
elif guess < secret:
    print("Мимо. Моё число больше, было", secret)
else:
    print("Мимо. Моё число меньше, было", secret)

5. Задачи и итог

Задачи под уроком — от простой к трудной: «Знак числа» → «Оценка за тест» → «Трофеи после боя» → «Существует ли треугольник?» → «Високосный год». Последняя — со звёздочкой: условие из трёх частей со скобками.

⚠️ Задачи ОГЭ этого урока («Наименьший X», «Когда высказывание ложно», «9 запусков», «Подбери параметр A») используют то, чего ещё не было: break (остановить цикл) и цикл по списку пар for s, t in runs:. Покажи на одном примере — break это «нашли, хватит искать», а список пар — «готовый набор, for берёт по одной паре». Остальные ОГЭ-задачи можно оставить на потом: в тренажёре вариантов на сайте (ОГЭ → №3 и №6 → «🎲») они решаются без программы, рассуждением.

по ходу

Факты к уроку — 2–3 на выбор

  • Джордж Буль (1854). Английский математик описал «алгебру логики», где есть только два значения — истина и ложь, и операции И, ИЛИ, НЕ. Поэтому тип True/False в программировании называется bool — в честь Буля. Через 80 лет Клод Шеннон показал, что по этим правилам можно строить электрические схемы, — так алгебра Буля стала основой всех компьютеров.
  • Високосный год. Правило «делится на 4, но не на 100, или делится на 400» ввёл григорианский календарь в 1582 году. Россия перешла на него в 1918-м: после 31 января сразу наступило 14 февраля. Поэтому Октябрьская революция отмечалась 7 ноября.
  • Возрастные рейтинги. Знаки 0+, 6+, 12+, 16+, 18+ на фильмах и играх — это и есть «фейсконтроль» из примера, только записанный в законе.
