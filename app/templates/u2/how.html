Как считается прогноз

1. Шанс решить каждый номер

По каждому номеру экзамена мы держим одно число — шанс решить его на экзамене. Пока ты номер не трогал, шанс {{ k.prior }} %: пока о тебе ничего не известно, считаем осторожно. Если на старте ты сам отметил, как умеешь, — берём твою оценку.

После каждой попытки шанс сдвигается к результату: верно — вверх, неверно — вниз. Первые попытки двигают его сильно (до {{ k.first }} % расстояния), чтобы прогноз быстро нащупал твой уровень, потом всё мягче (не меньше {{ k.min }} %), чтобы одна случайная ошибка не обрушила всё.

Пример. Номер, который ты раньше не решал, и четыре попытки подряд:

  1. {{ s.label }} → шанс {{ s.p }} %
    2. {% endfor %}

2. Забывание

Без практики навык тает: за {{ k.half }} дней без попыток шанс возвращается к стартовым {{ k.prior }} % наполовину, ещё за {{ k.half }} — ещё наполовину. Поэтому номер, который ты не открывал {{ k.review }} дней и больше, план сам вернёт как повторение.

3. Из номеров — в баллы

Ожидаемый первичный балл — сумма по всем номерам: шанс × баллы за номер. Номер на 2 балла с шансом 50 % даёт 1 ожидаемый балл.

Вилка — диапазон, в который результат попадёт примерно в 8 случаях из 10. Пока попыток мало, мы честно не уверены — вилка широкая. С каждой попыткой она сужается.

Первичный балл переводим по официальной шкале: в отметку для ОГЭ и базовой математики, в тестовый балл для ЕГЭ. Если для отметки нужны баллы за отдельную часть (например, за геометрию), это тоже учитывается.

4. План на сегодня

Каждому номеру считаем, сколько баллов прибавит минута тренировки: чем ниже шанс и дороже номер, тем больше выигрыш, но долгие задания делятся на своё время. В план по очереди берём самый выгодный номер. После каждого шаг выигрыша по нему уменьшается — одна тренировка закрывает примерно {{ k.learn }} % пробела, — поэтому слабый номер может встать в план до {{ k.reps }} раз, но только пока он выгоднее остальных.

Номер считается освоенным, когда решён верно {{ k.streak }} раза подряд. Ошибка после этого — сигнал, что он «проседает»: такие номера видны во вкладке «Прогресс».

Чего прогноз не знает

Он не видит волнения, усталости и почерка, а по номерам с развёрнутым ответом опирается на твою собственную оценку — поэтому отмечай баллы честно. Прогноз — ориентир для подготовки, а не обещание результата.
