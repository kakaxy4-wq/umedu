# Свой сайт: для школы, кружка или репетитора

Один экземпляр — один преподаватель и его ученики (до 30). Данные хранятся в одном файле SQLite на вашем сервере.

## Docker (проще всего)

Нужен сервер с Docker и домен, направленный на него.

```bash
git clone <адрес репозитория> umedu && cd umedu
cp .env.example .env            # впишите CQ_BASE_URL и CQ_SITE_NAME
docker compose up -d --build
docker compose run --rm web python manage.py init     # учётка преподавателя: пароль вводите сами
```

Сайт слушает порт 8000. HTTPS включите в своём обратном прокси (Caddy, nginx, Traefik) — без HTTPS вход не работает,
пока не поставить `CQ_COOKIE_SECURE=0` (только для проверки на своём компьютере).

Обновление: `git pull && docker compose up -d --build`. База — в томе `umedu-data`, переживает обновления.
Резервная копия: `docker compose exec web python manage.py backup` — копия ляжет в `/data/backups/` внутри тома.

## Без Docker

Python 3.12:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
bash scripts/fetch_vendor.sh
CQ_DATA_DIR=/var/lib/umedu python manage.py init
CQ_DATA_DIR=/var/lib/umedu uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Запуск как службы — любой менеджер процессов (systemd, supervisor).

## Настройки (`.env`)

| Переменная | Что делает |
|---|---|
| `CQ_SITE_NAME`, `CQ_BRAND_EMOJI` | название и значок |
| `CQ_BASE_URL` | адрес сайта, для ссылок родителям |
| `CQ_SUBJECTS` | предметы: `python`, `russian`, `chemistry` (через запятую) |
| `CQ_THEME` | `public` — нейтральные игровые слова и лендинг `/welcome` |
| `CQ_SIGNUP` | `0` — учеников заводит преподаватель; `open` — ученики регистрируются сами, без кода, в самостоятельном темпе (с согласием на обработку данных и ограничением 5 регистраций в час с адреса); `1` — по коду приглашения (только для химии) |
| `CQ_MAX_STUDENTS` | сколько активных учеников принимает сайт (по умолчанию 30) |
| `CQ_OPERATOR` | кто оператор персональных данных — для страницы `/privacy` |
| `CQ_CONTACT` | ссылка «связаться» на лендинге |
| `CQ_SOURCE_URL` | ссылка на исходный код вашей версии — по AGPL-3.0 её нужно показывать, если вы меняли код |
| `CQ_TELEGRAM_TOKEN`, `CQ_TELEGRAM_CHAT_ID` | бот из @BotFather и ваш чат — уведомления и сводка недели преподавателю |
| `CQ_PARENT_BOT` | `1` — родители подключают бота в своём кабинете и получают отчёт по воскресеньям. Бот читает сообщения (getUpdates), поэтому этот токен не должен использоваться больше нигде |
| `CQ_TIMEZONE` | часовой пояс, по умолчанию `Europe/Moscow` |
| `CQ_UMEDU2` | `1` — включить раздел umedu 2.0 (`/u2`): подготовка к ОГЭ и ЕГЭ с прогнозом балла. Без флага раздел отвечает 404 |

## Персональные данные

Вы — оператор данных своих учеников. Страница `/privacy` — шаблон: проверьте его и укажите себя в `CQ_OPERATOR`.
Кабинет родителя спрашивает согласие и хранит его дату и редакцию.

## umedu 2.0: подготовка к ОГЭ и ЕГЭ с прогнозом

Раздел `/u2` включается флагом `CQ_UMEDU2=1` и перезапуском. Отдельной базы не нужно: таблицы появляются сами при
старте (`CREATE TABLE IF NOT EXISTS`), старые данные не трогаются. Выключить — убрать флаг: данные останутся.

Что получает ученик:

- выбор экзаменов и цели (отметка или тестовый балл), дата экзамена подставляется из проекта расписания 2027;
- прогноз с вилкой, план на день под выбранное время, тренажёр по номерам, мини-пробник на 25 минут;
- «Прогресс» по номерам, «Мои ошибки», серия дней и цель недели, прогноз к дню экзамена и путь к цели;
- страница `/u2/how` — как всё это считается.

Преподаватель видит класс по экзаменам на `/u2/class` (ссылка на пульте), родитель — прогноз в своём кабинете.

**Задания.** Номера с коротким ответом по математике (ОГЭ, ЕГЭ базовый и профильный), информатике и расчётные номера
физики генерируются кодом: условие и ответ строятся из пары «номер, сид», проверка — на сервере. Это собственные
задания по образцу кодификатора, не копии открытого банка ФИПИ. Остальные номера ученик решает по ссылке на банк
ФИПИ или из своего сборника и сам отмечает баллы.

**Что проверить перед запуском у себя.** Модели экзаменов — `app/content/exams/*.json`: поля `verified.*` = `false`
означают, что часть ещё надо сверить с документами ФИПИ и Рособрнадзора текущего года. Шкалы перевода в отметку —
рекомендации Рособрнадзора; если ваш регион утвердил свою шкалу, поправьте `scale` в JSON. Даты экзаменов —
`app/content/schedule-2027.json`, пока это проект расписания.
