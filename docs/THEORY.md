# «Разобраться» — теория перед номером

Короткий шаг перед каждым номером ОГЭ/ЕГЭ в /u2: правило, разобранный пример, типичные ошибки и сворачиваемое
«Углубиться». Цель — 2–4 минуты чтения: «как семечки», глубже — по желанию.

## Где лежит

`app/content/theory/<экзамен>-<NN>.md`, например `oge-math-09.md` → экзамен `oge-math-2026`, №9.

```
---
exam: ОГЭ
subject: математика
kim_number: 9
topic: Уравнения
source: Спецификация и кодификатор ФИПИ ОГЭ 2026
status: verified        # draft — лежит в репо, на сайте не показывается
checked: 2026-11-27
---
# Разобраться: №9. Уравнения
## Правило
## Разобранный пример     (строки «Шаг N.» становятся шагами, «Ответ: …» — плашкой)
## Типичные ошибки
## Углубиться             (<details><summary>…</summary> … </details>)
```

Формулы — `$…$` и `$$…$$`, подмножество TeX → MathML (`app/texmath.py`), без внешних библиотек. Неразобранная
формула показывается как есть; тест `tests/test_theory.py` требует, чтобы таких не было.

Любой HTML в тексте экранируется (кроме обёртки `<details>` в «Углубиться», её рисует шаблон).

## Как работает на сайте

- `/u2/train/<экзамен>/<N>`: пока ученик не открывал теорию, над заданием карточка «Шаг 1 из 2 · Разобраться».
  Задание не прячется — тему можно пропустить. После просмотра остаётся ссылка «Теория».
- `/u2/learn/<экзамен>/<N>`: страница теории. Открытие засчитывает шаг и обнуляет счётчик ошибок.
- Две ошибки подряд по номеру (подсказка после первой ошибки — тоже ошибка) → карточка «Вернуться к теории».
  Верный ответ обнуляет счётчик. Работает во всех тренажёрах: обычный ввод, русский, Робот, №16.
- Номер без проверенной теории работает как раньше, без шага.

Состояние — таблица `u2_theory` (создаётся сама при старте, `CREATE TABLE IF NOT EXISTS`).

## Как проверяли контент 27.11.2026

- 75 номеров: ответ в разобранном примере сверен с ответом генератора сайта на том же условии.
- 5 номеров пилота (ОГЭ мат. №6, 9, 10, 13, 14): пересчитаны вручную.
- Русский (16 номеров): методическая вычитка, исправлены «не» в сказуемом, чередование раст/рос, глухие
  согласные, «никому не помогли», отглагольное прилагательное, пример №3 заменён на другое предложение тренажёра.
