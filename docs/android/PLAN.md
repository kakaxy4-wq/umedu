## Закрыто, заново не решать

Kotlin + Compose, одна Activity. Живые предметы — те, где сервер сам выдаёт вариант и проверяет ответ (`u2_web.GENERATED`): ОГЭ математика, информатика, физика; ЕГЭ база, профиль, информатика, физика. Русский — «скоро», пока у него только самопроверка. Прогноз считает сервер тем же движком, что /u2 на сайте, второй формулы и своих таблиц у API нет.

Вход (решение владельца 29.10.2026): почта, VK ID, Яндекс ID. Telegram для входа не делаем. С 14 лет ученик регистрируется сам; младше 14 — аккаунт создаёт и подтверждает родитель. Старые ученики сайта входят тем же способом, что на сайте, — путь для них нужен до этапа 4. Учебный день — 04:00. Бэкап телефона выключен. Публичный выход — закрытая группа, потом открытая бета Play.
