# Часть 4. Качество, версии, откат

Принято. Установленную сборку нельзя заменить старой. Кто обновился, остаётся на ней, пока не поставит больший `versionCode`. Откатить приложение в магазине нельзя. Два механизма: остановить тех, кто ещё не обновился (Halt / не поднимать процент / не переключать `latest`), и погасить функцию у тех, кто уже на сборке (`GET /config`).

Прогноз считает сервер. В приложении нет второй формулы.

## Пирамида (ориентир ~250 тестов на публичную 1.0)

| Уровень | Доля | Сколько | Где | Готово когда |
|---|---|---|---|---|
| Модульные | 60% | ~150 | JVM, каждый PR | покрытие слоёв ниже |
| Контрактные | 15% | ~40 | PR сервера и приложения | один `openapi/v1.yaml` |
| UI Compose | 15% | ~40 сценариев | PR, позже Roborazzi | список сценариев, не строки |
| Скриншоты | отдельно | 18 экранов × темы × шрифт | PR: 18 светлых телефона; main: матрица | дифф > 0,1% валит |
| Интеграционные | 8% | ~20 | эмулятор, main и ночь | очередь и миграции |
| E2E | 2% | 5 | ночь и тег-кандидат | пять золотых путей |

Покрытие строками по репозиторию не смотрим.

| Слой | Порог |
|---|---|
| `:core:model` | 90% строк, 85% ветвлений |
| Сервер: `forecast.py` и `due_on` | 90% строк |
| Очередь и репозитории `:core:data` | 80% строк |
| ViewModel | не строки: у каждого Event — успех, пустой ввод, обрыв |
| Compose | нет порога строк |

Календарь — общие фикстуры Python и Kotlin: 03:59/04:00 Москва; Владивосток в 22:00 Москвы; 29 февраля 2028; DST Берлин; серия в 00:20; пропуск дня; comeback. `due_on` только сервер.

Контракт: `contract.lock` = SHA-256 YAML. Схема на сервере изменилась — приложение красное, пока лок не обновят. Сначала PR сервера.

Очередь: юнит «тот же ключ — одна попытка» на каждом PR. Ночной сценарий из двух запусков CI (force-stop нельзя внутри одного JUnit).

Мутации: только `forecast.py` и `due_on`, ночью, mutmut, 75% убитых. На приложение не распространяем.

Сбои: `POST /api/v1/crashes` (этап 8), белый список полей, тумблер в «Я». Sentry нет. StrictMode в debug роняет процесс.

## Процесс

Trunk-based. `feat/…`, `fix/…`, `chore/…`. В `main` не пушить напрямую. Чеклист PR — в `.github/pull_request_template.md`. Коммиты Conventional. CHANGELOG — git-cliff на теге.

`versionName` SemVer в `android/version.properties`. До публичной — `0.y.z`. `versionCode` целое, каждый выпуск +1.

| Workflow | Когда | Потолок |
|---|---|---|
| pr | каждый PR | 12 мин |
| main | push в main | 25 мин |
| release | тег `v*` | 30 мин наших шагов |
| hotfix | тег `v*-hotfix` | 15 мин |
| nightly | ночь | 40 мин, красный не блокирует main |

Ключи: не в git. Тег `v*` не собирать, пока нет трёх копий release-ключа. Play App Signing и сайт — разные подписи.

Миграции Room только вперёд. `fallbackToDestructiveMigration` в release нет.

Ступени магазина и runbook — `docs/android/RUNBOOK.md`.
