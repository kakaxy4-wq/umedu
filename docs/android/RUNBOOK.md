# Runbook «Плохой релиз»

Часы — наши действия, не модерация магазина. Быстрее магазина работает флаг в `GET /api/v1/config`.

Ориентир: от зелёного hotfix-тега до файла на сайте ~30 минут; до пользователей магазина — часы или двое суток. Сроки модерации на день первого выпуска — [ПРОВЕРИТЬ].

| Минута | Действие |
|---|---|
| 0 | Зафиксировать сборку, долю падений, теряется ли ответ. Sev-1 или нет |
| 5 | Play: Halt rollout. Процент назад не ползёт. RuStore: процент не уменьшать. Если кнопки стопа нет — готовить тот же хороший код с `versionCode + 1` |
| 10 | Выключить флаг сломанной функции (`CQ_API_FLAG_TRAINER=0` и т.п.). Безопасное значение уже в клиенте. Очередь на телефонах не удалять. Тренажёр гасить целиком только при порче ответов |
| 15 | Баг в API — откатить сервер или выключить путь флагом. Старые клиенты обязаны слать ответы. Откат, который требует нового поля от старого приложения, запрещён |
| 20 | Плашка через конфиг, без APK: «Эта часть на паузе. Ответы, которые ты уже дал, на месте» (`CQ_API_NOTICE_KIND=paused`) |
| 25 | Не трогать `hard_min_build` |
| 30 | Ветка `hotfix/x.y.z` от последнего хорошего тега. PATCH+1, versionCode+1 |
| 90 | Тест, красный на старом коде и зелёный на фиксе. Без него тег не ставим |
| 105 | Тег `vX.Y.Z-hotfix` |
| 120 | APK на сайт по версионной ссылке. `latest` — только если сломана и предыдущая публичная |
| дальше | Закрытая дорожка Play, потом 1% по ступеням. При Sev-1 не прыгать на 100% |

Sev-1: потерян ответ, испорчен прогноз, утекли персональные данные, нельзя пройти онбординг, падение на старте >5% сессий.

## Ступени

Внутренняя → закрытая (до 20 человек, 7 дней) → открытая бета → 1% → 10% (здесь сайт `latest`) → 50% → 100%.

RuStore первой витриной не делаем: первую версию там нельзя отдать на 1%.

Немедленно останавливаем набор, если за 50 сессий доля без падения < 98%, или есть потеря ответа, или `hard_min_build` выше текущей публичной.

Правило семи дней: если ступень висит 7 дней, падения прочитаны и доля без падения ≥ 99% — переходим без порога сессий.
